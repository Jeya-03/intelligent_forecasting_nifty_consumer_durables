This project proposes an AI-driven framework for stock market forecasting that combines transformer-based deep learning with LLM-enabled decision-making. The model predicts closing prices of the NIFTY Consumer Durables index using multi-head attention to capture temporal trends. Predictions are validated through two approaches: Neuro-Symbolic AI for rule-based reasoning and an Advanced AI Agent Architecture leveraging LLMs, external financial data, and historical memory. This hybrid approach improves accuracy, adaptability, and interpretability in financial forecasting. By integrating deep learning with symbolic reasoning, the framework delivers reliable, explainable predictions, supporting informed investment decisions and advancing AI-based financial market analysis.
